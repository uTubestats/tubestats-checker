About TubeStats Checker

TubeStats Checker is a small, free tool for looking up the public statistics of a YouTube video or Short.

What it does

You paste a link. The site asks the official YouTube Data API v3, through its own server, for the video’s public details and shows them in one place: title, thumbnail, channel, publish date, views, likes and comments, plus a like-to-view ratio calculated from those figures.

What it does not do

It does not access private analytics, scrape YouTube pages, or estimate numbers. If the API does not return a figure, the site shows it as unavailable.
